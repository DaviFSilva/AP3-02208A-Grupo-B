# AP3-02208A-Grupo-B

Avaliação 3 - Sistemas Digitais - UFSC

Nosso projeto é sobre uma ULA em VHDL 2008 com as seguintes operações:

ULA:
- Adição
- Subtração
- Incremento (+1)
- Decremento (-1)
- Left Shift
- Right Shift
- Logic (AND, OR, XOR, NOT)
- Multiplicação
- Divisão
- Raiz Quadrada
- Exponenciação
